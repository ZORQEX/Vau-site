# Vau-site
ВАУ‑Сайт — это одностраничный (SPA) лендинг с интерактивными элементами, созданный на чистом HTML/CSS/JavaScript без фреймворков.

Назначение сайта
Это демонстрационный/витрина-сайт, который может использоваться для:

Рассказа о сервисе или продукте
Сбора обратной связи от пользователей (оценки, комментарии, сообщения)
Портфолио или практическое задание по веб-разработке
Плюсы этого сайта:
1. Современный дизайн

Градиентный фирменный стиль (тёмно-синий → фиолетовый с неоновыми акцентами)
Анимации появления элементов (fadeInUp, вращающийся фон)
Адаптивность под мобильные устройства
2. Интерактивность

Плавная прокрутка к секциям при клике на меню
Анимация при наведении на карточки и изображения галереи
Система звёздных оценок (5 звёзд) с сохранением в localStorage
3. Функционал для взаимодействия с пользователем

Галерея изображений с hover-эффектами
Форма обратной связи (имя, email, сообщение)
Блок комментариев с привязкой к оценке
Отдельная страница для просмотра всех комментариев и сообщений
4. Техническая простота

Нативный JavaScript без зависимостей
Данные сохраняются в localStorage (не требует сервера)
Лёгкий для хостинга (GitHub Pages, Netlify, Vercel)
5. Безопасность

Экранирование HTML-символов в комментариях (защита от XSS)
